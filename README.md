# NEXUS — Biology Button Prototype

This repository has a homepage and a browser-preview setup for GitHub Codespaces.

## Open the preview

1. Open this repository in **GitHub Codespaces** (not the `github.dev` code editor).
2. If asked, rebuild the Codespace so it installs dependencies.
3. Open the terminal and run `npm run dev`.
4. Open forwarded port **5173** when Codespaces shows it. You will see the page in a browser without copying code into OneCompiler.

The preview homepage is `index.html`. The standalone version is `biology-button.html`.

## Reference image

The page expects `biology-reference.jpg` in the repository root. The image itself is not in the repository yet, so the artwork will remain a placeholder until that file is uploaded with this exact name.
